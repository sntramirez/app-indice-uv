# Assets

Esta carpeta está destinada para contener assets de la aplicación como íconos e imágenes splash.

Para agregar íconos personalizados a tu aplicación:

1. **Ícono de la app** (`icon.png`): 1024x1024 px
2. **Splash screen** (`splash.png`): 1242x2436 px
3. **Favicon** (`favicon.png`): 48x48 px (para web)
4. **Adaptive icon** (`adaptive-icon.png`): 1024x1024 px (Android)

Por ahora, la aplicación funciona sin estos assets usando configuraciones predeterminadas de Expo.

Para generar íconos automáticamente, puedes usar:
- https://www.appicon.co/
- https://makeappicon.com/
